# MCP Tool Registration

This folder contains the SDK registration code for PangoLint MCP tools.

- `commandKnowledgeTools.ts` registers command lookup and search tools.
- `objectTreeKnowledgeTools.ts` registers Object Tree lookup and search tools.
- `propertyControlTools.ts` registers property control reference tools.
- `scriptAnalysisTools.ts` registers linting, diagnostic explanation, and server configuration tools.
- `runtimeReadTools.ts` registers readback-only runtime checks and Object Tree reads.
- `runtimeWriteTools.ts` registers operator-gated script execution.
- `toolRegistrationTypes.ts` keeps the shared registration context shape.
- `toolRegistrationResult.ts` keeps the shared text plus structured result shape.
