# PaingoScripts Examples

This folder contains `.BeyondCode` scripts from
[PaingoScripts](https://github.com/jvyduna/PaingoScripts), included in
PangoLint with attribution and maintainer-confirmed permission from
Jeff Vyduna.

Upstream attribution:

- PaingoScripts repository owner: Jeff Vyduna.
- The upstream README attributes these scripts to Lyra Letourneau:
  - `Autosave workspace every X minutes.BeyondCode`
  - `Automate a daily cue schedule and system restart.BeyondCode`
  - `Mirror (reverse X) half the zones.BeyondCode`
  - `Tap tempo from DMX lighting console.BeyondCode`
  - `Fade volume out and restart timelime.BeyondCode`
- The remaining scripts are listed upstream under Jeff Vyduna.

The upstream repository states that PaingoScripts is licensed under
CC BY-SA 4.0. See `LICENSE.md` in this folder for the upstream license notice.

PangoLint preserves these files as attributed examples, with CRLF line endings
and trailing whitespace normalized for BEYOND paste compatibility and
repository hygiene. `npm run lint:examples` reports diagnostics from this
folder as informational so upstream script behavior remains intact.
